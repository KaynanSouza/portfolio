deploy/load-balancer ns: academico

loadBalancing featured

Load balancer em Go que distribui tráfego entre pods NGINX via API Proxy do Kubernetes. Cada backend tem um reverse proxy próprio com ErrorHandler para lidar com falhas, e um health check TCP periódico tira do pool o que não responde.

  • 7 estratégias: Round Robin, WRR, IP Hash, P2C, Least Latency, Fewest Conn, Always First
  • Métricas por pod comparando Round Robin, IP Hash e Least Latency
