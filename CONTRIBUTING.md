# Guia de Colaboração

Obrigado por contribuir com o PortfolioHUB.

## Fluxo de trabalho

1. Abra uma **issue** descrevendo o que e por quê, principalmente em mudanças grandes.
2. Crie uma branch a partir da `main`:
   - `feat/nome-curto` para novidades
   - `fix/nome-curto` para correções
   - `docs/nome-curto` para documentação
3. Faça commits pequenos, no padrão `tipo: descrição` (`feat`, `fix`, `docs`, `chore`).
4. Abra um **Pull Request** usando o template e resolva todos os comentários da revisão.
5. Após o merge, o GitHub Pages republica o site automaticamente.

## Regras

- Nunca faça commit direto na `main`.
- Não inclua senhas, tokens, chaves ou dados pessoais em nenhum arquivo.
- Cada projeto fica em sua própria pasta, com um `README.md` contendo descrição, tecnologias, como executar e status.
- Nomes de pasta em minúsculas, com hífen.
- Atualize o README principal quando adicionar ou remover um projeto.

## Revisão

Os Pull Requests são revisados em até dois dias úteis. Veja [SECURITY.md](SECURITY.md) para falhas de segurança, que devem ser reportadas em privado.
